# System vision

A local computational workbench and dependable tool for agents, covering Western,
Jyotisha, relationship and location techniques, with extensible tradition profiles.
An agent discovers capabilities, asks for missing inputs, chooses an explicit
profile, computes, then interprets results with traceable rules and uncertainty.

The CLI and Python API work offline given coordinates and an IANA timezone.
Optional adapters resolve places, render charts/maps, and expose agent protocols.
The core never depends on an LLM or a hosted service. Mobile, browser and embedded
clients use adapters; native support is a roadmap item with separate build gates.

Success: a chart can be reproduced from its request, software/ephemeris versions,
method selection and rule data. A tradition is advertised only at the scope that
its implemented methods and independent fixtures support.
