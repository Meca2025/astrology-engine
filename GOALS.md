# Execution goals

Build the architecture and capability roadmap first, then deliver small complete
slices with computation, agent/CLI access, tests, interface docs and verified pushes.

Immediate gate: S01 chart contracts and correctness foundation. Next: S02 Vedic D1,
S03 divisional charts, S04 Vimshottari timing, S05 panchanga, S06 relationships,
S07 location computation, S08 advanced Western tools. Remaining research and
integration stages are specified in ROADMAP with explicit readiness gates.

Every slice records target, owner, before/after behavior, invariants, concrete files,
verification, known limits and next slice. Passing local tests is not equivalent to
independent tradition validation or physical-device certification.
